# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Язык

Отвечать пользователю по-русски. Комментарии в коде и спеки тоже на русском.
По-английски: `README.md` и сообщения коммитов — лицо публичного репозитория, —
тексты, которые видит пользователь Claude Code (см. `deny()` в `hook.go`), а
также сообщения об ошибках настройки.

## Комментарии

Держать в пределах трёх строк. Комментарий отвечает «почему так», а не «что
делает код»; развёрнутое обоснование — решения, отвергнутые альтернативы,
последствия — место в спеке (`openspec/specs/`) или в `design.md` изменения, и
из кода на них ссылаются, а не переписывают их заново. Существующие длинные
комментарии переписывать без нужды не надо, но новые по их образцу не писать.

## Команды

```sh
make                      # vet + test + build
make test                 # go test ./... — без эмуляторов и без обращения к реестрам
make emulators AVD=<образ> # тесты на настоящих инстансах, за тегом emulators
make build                # bin/emulator-router
make fmt                  # gofmt -l -w .
go test ./cmd/emulator-router -run TestAcquireRespectsCap -v   # один тест
make run ARGS="status"    # go run с аргументами
```

## Архитектура

Один бинарь `cmd/emulator-router`, весь код в пакете `main`, четыре файла:

- `main.go` — `config` (настройки + швы `Run`/`Spawn`/`Signal`/`Now`/`Sleep`), `defaultConfig()`, файл настроек проекта (`settings`, `findSettings`, `applySettings`), разбор подкоманд в `dispatch()`. `config` не приёмник методов: значение кладётся в контекст (`cfgKey` из `internal/ctxkey`) и достаётся хелпером `cfg(ctx)`, поэтому все функции пула и хука принимают `ctx` первым аргументом.
- `pool.go` — реестр на файлах, взаимное исключение, жизненный цикл инстансов (`acquire`/`release`/`reap`/`mine`).
- `hook.go` — обработка событий хука Claude Code: `PreToolUse` и `SessionEnd`.
- `doctor.go` — проверка предусловий: статические проверки, затем один настоящий инстанс.

## Настройки

Настраивается только то, что различается между проектами: образ (обязателен,
дефолта нет), предел инстансов, ускоритель графики, список обёрток, обслуживание
главного чекаута. Источник — файл `.claude/emulator-router.json`, который ищется
вверх от рабочего каталога вызова. Переменных окружения для этих настроек нет:
настройка, не видимая в репозитории проекта, не воспроизводится у второго
участника и не переживает перезапуск сессии.

Не настраивается: расположение реестра, диапазон портов, все пределы времени,
остальные аргументы запуска инстанса (в частности `-read-only`, снятие которого
роутер отдельной ветвью запрещает делать вручную). Расположение SDK берётся из
`ANDROID_HOME`/`ANDROID_SDK_ROOT` либо из стандартного расположения платформы —
это свойство машины, а не проекта.

Два разных ответа на похожие ситуации намеренны: файл не найден — пул молчит и
вызов исполняется (хук подключают глобально, и в непричастном проекте он обязан
быть безвредным); файл найден, но негоден — код 2, вызов блокируется.

## Спеки

Проект ведётся по OpenSpec (`openspec/`): `specs/hook-routing`,
`specs/emulator-pool`, `specs/pool-configuration` — действующее поведение,
`changes/` — предложенные изменения. Поведение меняется через изменение в
`changes/` (`/opsx:propose`, `/opsx:apply`), а не правкой спеки напрямую.
При `/opsx:archive` дельты спек синхронизируются в основные спеки без вопроса,
если пользователь не сказал иного.

## Что важно не сломать

- **Имя события в решении.** `emit` проставляет `hookEventName` в каждый вывод. Claude Code разбирает `hookSpecificOutput` размеченным объединением по этому полю и без него отбрасывает решение целиком — молча, то есть вызов уходит на произвольное устройство. Закреплено тестом `TestEveryDecisionNamesTheEvent`.
- **Требование позиции команды.** Навешивается роутером (`commandPos`) и на ядро распознавания, и на каждый шаблон из настроек. Гарантия «упоминание слова внутри кавычек не занимает инстанс» не должна зависеть от аккуратности того, кто настройки писал.
- **Освобождение при `SessionEnd` безусловно** — до и независимо от разбора настроек.
