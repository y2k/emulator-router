## ADDED Requirements

### Requirement: Изменённый ввод сохраняет остальные аргументы вызова

Изменённый ввод в решении заменяет ввод вызова целиком, а не сливается с ним по
полям. Поэтому система SHALL включать в изменённый ввод все поля исходного ввода
вызова, переопределяя только те, которыми вызов привязывается к инстансу:
аргумент выбора устройства у вызовов Mobile-MCP и команду у вызовов оболочки.
Поля, значения которых не являются строками, SHALL передаваться с сохранением
своего типа.

Утрата поля не сводится к потере удобства. Обязательный аргумент инструмента
Mobile-MCP делает вызов негодным по схеме самого инструмента, а признак фонового
исполнения и предел времени у вызова оболочки меняют способ исполнения команды:
вызванная в фоне сборка становится синхронной и прерывается по дефолтному
пределу.

Система не SHALL добавлять в изменённый ввод поля, которых не было в исходном
вводе, кроме переопределяемых: значение по умолчанию, выдуманное системой,
неотличимо для инструмента от заданного вызывающей стороной.

#### Scenario: Вызов Mobile-MCP с обязательными аргументами помимо устройства

- **WHEN** приходит вызов инструмента Mobile-MCP, обязательные аргументы которого
  включают не только устройство, и часть их значений не является строками
- **THEN** изменённый ввод содержит все эти аргументы с исходными значениями и
  типами, а аргумент устройства заменён на серийник инстанса этой сессии

#### Scenario: Вызов оболочки с признаком фонового исполнения

- **WHEN** приходит вызов оболочки, обращающийся к эмулятору, с заданным
  признаком фонового исполнения
- **THEN** изменённый ввод содержит этот признак с исходным значением, а команда
  переопределена привязкой к инстансу этой сессии

#### Scenario: Вызов оболочки с заданным пределом времени

- **WHEN** приходит вызов оболочки, обращающийся к эмулятору, с заданным пределом
  времени исполнения
- **THEN** изменённый ввод содержит этот предел с исходным значением

#### Scenario: Вызов без дополнительных аргументов

- **WHEN** исходный ввод вызова не содержит полей, кроме переопределяемого, либо
  пуст
- **THEN** изменённый ввод содержит только переопределённое поле
