## Why

Claude в чужом проекте о роутере знает только то, что сообщает сам хук: строку
«This session owns emulator …» при обращении к устройству и причину отказа. Этого
не хватает в двух случаях. Подключить роутер к проекту некому подсказать: пока
он не настроен, хук молчит, а README лежит в этом репозитории, а не в
подключаемом. В подключённом проекте не видно того, о чём хук не говорит: что
инстанс убирают после простоя вместе с установленным приложением, что обёртка,
не перечисленная в `reach`, уходит мимо пула молча, и куда смотреть, когда
инстанс пропал.

## What Changes

- В корне репозитория появляется каталог `skills/` с двумя скиллами Claude Code:
  - `emulator-router-setup` — подключение пула к проекту и починка настройки:
    установка, подключение хуков с пределом времени, файл настроек, подготовка
    образа со снапшотом, проверка `doctor`;
  - `emulator-router-usage` — работа с устройством в подключённом проекте:
    чего не делать с серийником, что означает уборка по простою, как отвечать
    на каждый вид отказа, как диагностировать через `status` и `log`.
- Скиллы ставятся вручную: каталог скилла линкуется в `.claude/skills/` нужного
  проекта. Плагина, встраивания в бинарь и команды установки нет.
- Скиллы не переписывают то, что бинарь сообщает сам (перечень подкоманд, коды
  возврата, отчёт `doctor`, тексты отказов), а отправляют к нему.
- README получает раздел о скиллах и о том, как их подключить.
- Тест сверяет скиллы с бинарём: каждая упомянутая в них подкоманда
  распознаётся, имя скилла совпадает с именем его каталога.

Не входит в изменение: плагин Claude Code и доставка хуков через него, подкоманда
установки скиллов, изменение текстов `additionalContext` и отказов хука.

## Capabilities

### New Capabilities

- `agent-skills`: скиллы, по которым Claude в чужом проекте подключает пул и
  работает с ним, — их назначение, разграничение, самодостаточность и
  согласованность с бинарём.

### Modified Capabilities

Нет: поведение хука, пула, настроек и справки не меняется.

## Impact

- `skills/emulator-router-setup/SKILL.md`, `skills/emulator-router-usage/SKILL.md` —
  новые файлы.
- `README.md` — раздел о скиллах.
- `cmd/emulator-router/router_test.go` — тест согласованности скиллов с
  `dispatch()`; сбор меток `switch` выносится из `TestHelpNamesEverySubcommand`
  в общий хелпер.
- Код роутера и внешние зависимости не меняются.
