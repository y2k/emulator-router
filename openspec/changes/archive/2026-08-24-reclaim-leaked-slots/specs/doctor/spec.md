## MODIFIED Requirements

### Requirement: Проверка условий, проявляющихся только на запущенном инстансе

Система SHALL проверять на реально запущенном инстансе условия, которые нельзя установить статически:

- инстанс поднимается загрузкой из снапшота, а не полной загрузкой;
- демон отладки инстанса не работает в режиме суперпользователя, поскольку снапшот, снятый в этом режиме, делает непригодными все клоны;
- права суперпользователя доступны для отдельной команды — их недоступность является нарушением, поскольку сценарии потребителя на них полагаются.

Если статические проверки уже обнаружили нарушение, проверки на запущенном инстансе SHALL пропускаться: запускать инстанс в заведомо сломанном окружении бессмысленно.

Запущенный для проверки инстанс SHALL быть освобождён по её завершении, включая случай, когда проверка завершилась нарушением.

Проверочная запись не SHALL переживать процесс проверки и в том случае, когда проверка прервана до освобождения. Для этого владельцем проверочной записи SHALL быть сам процесс проверки: запись с неопределённым владельцем считается принадлежащей живой сессии, и уборка не забирает её никогда, так что прерванная проверка занимала бы место в пределе до ручной чистки реестра.

#### Scenario: Снапшот не загружается

- **WHEN** проверочный инстанс поднимается полной загрузкой вместо загрузки из снапшота
- **THEN** результат содержит нарушение

#### Scenario: Демон отладки работает с правами суперпользователя

- **WHEN** на проверочном инстансе демон отладки работает в режиме суперпользователя
- **THEN** результат содержит нарушение

#### Scenario: Права суперпользователя недоступны для отдельной команды

- **WHEN** на проверочном инстансе команда с правами суперпользователя не получает эти права
- **THEN** результат содержит нарушение

#### Scenario: Статическая проверка обнаружила нарушение

- **WHEN** статические проверки обнаружили нарушение
- **THEN** проверки на запущенном инстансе не выполняются, и инстанс для них не запускается

#### Scenario: Проверка завершилась нарушением

- **WHEN** проверка на запущенном инстансе обнаружила нарушение
- **THEN** проверочный инстанс всё равно освобождается

#### Scenario: Проверка прервана до освобождения

- **WHEN** процесс проверки прекращён между выдачей проверочного инстанса и его освобождением
- **THEN** проверочная запись оказывается собираемой обычной уборкой, и место в пределе возвращается без ручного вмешательства
