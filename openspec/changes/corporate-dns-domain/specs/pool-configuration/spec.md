## MODIFIED Requirements

### Requirement: Состав настроек

Файл настроек SHALL содержать имя образа как обязательное поле: у образа для пула не существует общепринятого имени, поэтому дефолта у него быть не может.

Необязательными полями с дефолтами SHALL быть список распознаваемых обёрток, обслуживание главного чекаута и домен корпоративного DNS. Прочие настройки — расположение реестра, диапазон портов, все пределы времени, включая предел простоя, предел одновременных инстансов, ускоритель графики, расположение журнала решений — настройками проекта не SHALL быть.

Предел одновременных инстансов не SHALL быть настройкой проекта: сколько инстансов помещается, определяют память и диск машины, а не репозиторий. Записанное в репозитории число воспроизводит у второго участника само число, но не поведение. Ускоритель графики не SHALL быть настройкой проекта: его значение обязано совпадать с ускорителем, записанным в снапшот загрузки образа, иначе снапшот не загружается и каждый инстанс молча выполняет полную загрузку, — то есть оно продиктовано образом, а не выбирается проектом.

#### Scenario: Заданы только обязательные поля

- **WHEN** файл настроек содержит только имя образа
- **THEN** остальные настройки принимают значения по умолчанию, и домен корпоративного DNS не задан

#### Scenario: Задан предел инстансов

- **WHEN** файл настроек задаёт предел одновременных инстансов
- **THEN** файл негоден: код возврата равен 2, вызов заблокирован, а причина называет это поле

#### Scenario: Задан ускоритель графики

- **WHEN** файл настроек задаёт ускоритель графики
- **THEN** файл негоден: код возврата равен 2, вызов заблокирован, а причина называет это поле

#### Scenario: Задан предел простоя

- **WHEN** файл настроек задаёт предел простоя
- **THEN** файл негоден: код возврата равен 2, вызов заблокирован, а причина называет это поле

## ADDED Requirements

### Requirement: Корпоративный DNS задаётся доменом, а не адресом

Настройка корпоративного DNS SHALL задавать доменное имя зоны, которой нужен корпоративный DNS, а не адрес сервера. Какой зоне нужен корпоративный DNS, решает проект, и это одинаково у всех его участников. Адрес сервера — свойство сети машины: он меняется с VPN, и в репозитории он оставил бы инстанс без DNS на машине без VPN.

Значение, являющееся IP-адресом, либо пустая строка SHALL делать файл настроек негодным.

#### Scenario: Задан домен

- **WHEN** файл настроек задаёт домен корпоративного DNS
- **THEN** файл годен, и домен применяется

#### Scenario: Задан адрес вместо домена

- **WHEN** файл настроек задаёт в качестве домена корпоративного DNS IP-адрес
- **THEN** файл негоден: код возврата равен 2, вызов заблокирован, а причина называет поле и говорит, что ожидается домен

#### Scenario: Задана пустая строка

- **WHEN** файл настроек задаёт домен корпоративного DNS пустой строкой
- **THEN** файл негоден: код возврата равен 2, вызов заблокирован, а причина называет поле
