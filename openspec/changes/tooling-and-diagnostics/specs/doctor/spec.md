## MODIFIED Requirements

### Requirement: Проверка предусловий по запросу

Система SHALL по запросу выполнять набор проверок окружения и сообщать результат каждой проверки по отдельности, а не только итог.

Отчёт SHALL называть версию сборки, которой выполняется проверка. Проверка
отвечает на вопрос «почему пул ведёт себя не так», и ответом бывает устаревший
бинарь по прежнему пути: строка подключения хука содержит абсолютный путь, а из
какой сборки этот файл, не видно ниоткуда. Отсутствие версии в сборке SHALL
сообщаться наравне с самой версией, а не умалчиваться: собранный без версии
бинарь тоже надо уметь опознать.

#### Scenario: Все проверки успешны

- **WHEN** запрашивается проверка предусловий в исправном окружении
- **THEN** каждая проверка отмечена как успешная, код возврата равен 0

#### Scenario: Отчёт называет версию проверяющей сборки

- **WHEN** запрашивается проверка предусловий
- **THEN** отчёт содержит версию сборки, выполняющей проверку, либо явное
  указание, что версия в сборку не заложена
